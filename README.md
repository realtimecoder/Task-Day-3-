# Iris Dataset - Exploratory Data Analysis (EDA)

## Overview

This project performs Exploratory Data Analysis (EDA) on the Iris Dataset using Python. The objective is to understand the dataset, identify patterns, visualize relationships between features, and gain insights through statistical analysis and graphical representations.

## Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The project uses the Iris Dataset provided by Scikit-learn. No external dataset download is required.

Dataset contains:
- 150 samples
- 4 features:
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
- 3 species:
  - Setosa
  - Versicolor
  - Virginica

## Project Tasks

### Data Exploration
- Load dataset
- Display dataset information
- Check dataset shape
- Check missing values

### Statistical Analysis
- Generate summary statistics
- Analyze feature distributions

### Data Visualization
- Species distribution plot
- Histograms
- Boxplots
- Scatter plots
- Pairplots
- Correlation Heatmap

## Key Findings

- No missing values were found in the dataset.
- Petal Length and Petal Width show a strong positive correlation.
- Setosa species is clearly distinguishable from the other species.
- Versicolor and Virginica have slight overlap but can be separated using multiple features.
- Petal features provide better classification capability than sepal features.

## Output

The project generates:
- Summary Statistics
- Visual Graphs
- Correlation Heatmap
- EDA Report

## How to Run

1. Open Google Colab or Jupyter Notebook.
2. Copy and run the provided Python code.
3. All visualizations and analysis results will be generated automatically.
